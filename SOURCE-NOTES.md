# Official-source boundaries — checked September 10, 2026

- https://flop.finance/intro/yellowpaper/ is an implementation draft, not proof of
  public deployment. Its open items include unresolved allocation/vesting details.
- https://flop.finance/teaser/ describes testnet inference and prizes as intended
  agent participation routes; it does not establish a reward for this package.
- https://flop.finance/apply/kol redirects to the official creator-interest form.
  Submission does not guarantee selection, tokens or payment. Required operator
  profile/contact fields must be supplied before a truthful application is possible.
- https://github.com/flop-labs/tclk/issues/26 supplies the original duplicate-key
  interoperability question. The proposed patch remains an unsubmitted local revision.

The preceding research reported a proposed creator/referral initiative, not a live
enrollment or permission to self-refer. Existing-wallet terms remain unverified.
This package does not rely on social copies to activate any capability.

Before live inference, capture and hash current authoritative specifications for
account binding, endpoints, model identity, fee units, settlement/read-back,
idempotency, timeout outcomes and participant restrictions. Resolve discrepancies
between older overview text and the implementation draft. Require independent
adapter review and exact operator-approved limits. Presently all such execution
capabilities remain disabled; absence of verification is not proof of deployment.
